1️⃣ Composants

Liste du matériel nécessaire pour réaliser le projet IoT avec ESP32.

  • Carte ESP32
  • Capteur DHT11
  • LED
  • Résistance 220Ω
  • Câbles Dupont
  • Breadboard

2️⃣ Branchement

Schéma de connexion des composants à la carte ESP32.

  • DHT11 → VCC vers 3.3V
  • DHT11 → GND vers GND
  • DHT11 → DATA vers GPIO 4
  • LED → GPIO 2 avec résistance 220Ω

3️⃣ Code Arduino IDE

Programme Arduino pour lire la température via le capteur DHT11 et activer une LED si la température dépasse 30°C.

📥 Télécharger le fichier Arduino (.ino)

4️⃣ Code MicroPython

Programme MicroPython transformant l’ESP32 en serveur IoT avec stockage CSV, affichage OLED et visualisation graphique web.
