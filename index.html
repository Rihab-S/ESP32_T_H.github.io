1️⃣ Composants

  • Carte ESP32
  • Capteur (ex: DHT11)
  • LED
  • Résistance 220Ω
  • Câbles Dupont
  • Breadboard

2️⃣ Branchement

  • DHT11 → VCC vers 3.3V
  • DHT11 → GND vers GND
  • DHT11 → DATA vers GPIO 4
  • LED → GPIO 2 avec résistance

3️⃣ Code Arduino IDE

#include "DHT.h"

#define DHTPIN 4
#define DHTTYPE DHT11
#define LED 2

DHT dht(DHTPIN, DHTTYPE);

void setup() {
  Serial.begin(115200);
  dht.begin();
  pinMode(LED, OUTPUT);
}

void loop() {
  float temp = dht.readTemperature();
  Serial.println(temp);

  if(temp > 30){
    digitalWrite(LED, HIGH);
  } else {
    digitalWrite(LED, LOW);
  }

  delay(2000);
}

4️⃣ Code MicroPython

import machine
import dht
import time

sensor = dht.DHT11(machine.Pin(4))
led = machine.Pin(2, machine.Pin.OUT)

while True:
    sensor.measure()
    temp = sensor.temperature()
    print(temp)

    if temp > 30:
        led.on()
    else:
        led.off()

    time.sleep(2)
